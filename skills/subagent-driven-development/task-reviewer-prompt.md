# 任务或批次审查者模板

读取 [BRIEF_FILE]、[REPORT_FILE]、[DIFF_FILE] 和 [VERIFICATION_WORKSPACE] 账本，对照实际需求核查规格与代码质量。简报含有效验证策略；本次审查范围由 [BASE_SHA]..[HEAD_SHA] 和 [REVIEW_SCOPE] 确定。

只读审查，不修改工作树、索引或 HEAD，不派发任何子代理。默认只读已提供差异；只有点名具体风险时才查看必要调用点。实现报告是需要核查的声明，证据缺失先读取对应日志，不为了重建证据重跑测试。

low 无单元测试、未使用 TDD 或没有完整套件不能单独判错。检查策略是否符合风险、验收是否满足、证据与当前相关内容是否一致。发现现有证据无法回答的具体疑问，返回建议的最小检查给控制者，不自行运行。

报告：规格合规性、代码质量、附 file:line 的具体发现（Critical/Important/Minor）、证据缺口及建议检查。严重度依据真实影响，不因为规格没写就降级。低风险验证预算不能掩盖真实严重缺陷。结论不超出已核实范围。
